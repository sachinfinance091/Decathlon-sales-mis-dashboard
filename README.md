# Retail Sales & Customer Analytics – Excel MIS Dashboard

## Project Overview
This project is an interactive Retail Sales & Customer Analytics MIS Dashboard developed using Microsoft Excel and Power Query.

The dashboard provides a consolidated view of retail business performance, helping users monitor sales, orders, customers, product categories and customer retention.

## Dashboard Preview

![Retail Sales MIS Dashboard](Dashboard_Preview.png)

## Key Performance Indicators (KPIs)

- **Total Sales:** ₹36.7 Crore
- **Total Orders:** 30,000
- **Total Customers:** 8,998
- **Average Order Value:** ₹12,236

## Key Dashboard Features

1. Sales Performance Analysis
2. Monthly Sales Trend
3. Sports Category Performance
4. Customer Retention Analysis
5. Gender-wise Sales Analysis
6. Year-wise Performance Selection
7. Key Business Insights

## Tools & Technologies

- Microsoft Excel 2021
- Power Query
- Pivot Tables
- Excel Charts
- Slicers and Interactive Filters

## Business Insights

- Monitored total sales performance of ₹36.7 Crore.
- Analyzed 30,000 customer orders.
- Evaluated customer growth and retention.
- Identified top-performing sports categories.
- Compared sales performance across different periods.

## Project Objective

To develop an interactive MIS dashboard that transforms retail sales data into meaningful business insights and supports data-driven decision-making.
